# Neteja Pro

Aplicacio web estatica per coordinar serveis recurrents de neteja, treballadors, vacances, absencies i assignacions optimes.

## Funcions principals

- Planificacio setmanal, diaria i anual de serveis recurrents.
- Assignacio de treballadors amb puntuacio per zona, disponibilitat, historial, qualitat, cost i carrega horaria.
- Mode esborrany per provar reassignacions abans de confirmar-les.
- Simulacio de baixes i recalcul de serveis afectats.
- Fitxes de client amb preferencies, vetos, continuitat i regles de canvi.
- Calendari de vacances de clients i treballadors.

## Publicacio

El projecte es pot servir directament amb GitHub Pages des de l'arrel del repositori. Els fitxers principals son:

- `index.html`
- `styles.css`
- `app.js`

Per desenvolupar localment:

```bash
node server.mjs
```

I obre `http://localhost:5173/`.
